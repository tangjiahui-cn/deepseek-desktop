# 桌面端冒烟清单

用于每次发版前在真实安装包上验证桌面外壳；Web 版回归见 `pnpm build` 后的手动检查。

## 环境准备

- 至少一台 macOS（arm64）与一台 Windows；Linux 可用 AppImage 与 deb 各装一次。
- 准备一个可用的 DeepSeek API Key。
- 清除旧数据：退出应用，删除对应平台的 `DeepSeek Desktop` 数据目录（见 README「数据」）。
- 安装待测版本，记录版本号与安装包文件名。

## 已知限制

- macOS 未签名，首次安装需在「隐私与安全性」中放行。
- `navigator.clipboard.writeText` 会被权限策略拒绝；应用的复制按钮会回退到 `document.execCommand('copy')`，实测可用。
- 本地验证在受限沙箱中以 `--no-sandbox` 启动，未验证真实下载包的 Gatekeeper 弹窗；`spctl` 对未签名构建给出拒绝评估，正式分发前建议补签名。
- macOS 与 deb 不在应用内安装更新，只跳转发布页。
- 开发模式与正式安装使用不同的 `userData` 目录，不共享会话。
