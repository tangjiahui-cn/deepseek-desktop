# Spec Delta

## MODIFIED Requirements

### Requirement: 更新检查

打包后的应用 SHALL 在界面可用后自动检查一次更新，并允许用户从菜单或设置中的「版本信息」检查；进入「版本信息」分组时自动检查一次。未打包的开发模式不得发起更新检查。

#### Scenario: 启动后自动检查
- **WHEN** 已安装的应用启动并完成界面加载
- **THEN** 应用在后台检查更新，不阻塞聊天界面

#### Scenario: 手动检查
- **WHEN** 用户从菜单选择「检查更新」
- **THEN** 应用立即检查，并在无更新时给出明确反馈

#### Scenario: 设置中检查
- **WHEN** 用户进入设置「版本信息」分组或点击「刷新」
- **THEN** 应用立即检查，并在分组内显示结果；无更新时明确提示

#### Scenario: 开发模式
- **WHEN** 以未打包的开发模式运行
- **THEN** 应用不发起任何更新检查请求
