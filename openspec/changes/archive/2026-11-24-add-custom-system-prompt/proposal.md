# Proposal

## Why

当前所有聊天请求只携带固定的助手身份说明，用户无法把自己的表达偏好、角色设定或格式要求稳定地带给模型；每次对话手动重复输入既不统一，也无法跨会话保留。设置弹窗目前只有「通用设置」与「数据管理」，缺少一个集中管理个性化内容的位置。

## What Changes

- 设置弹窗新增「个性化」分组：桌面端出现在左侧导航，移动端出现在横向标签栏，默认顺序位于「通用设置」与「数据管理」之间。
- 「个性化」分组内新增「提示词」多行输入，最多 2000 字，带实时字数统计；内容自动保存到本机设置，重新打开应用后恢复。
- 所有模型生成请求在固定身份说明（`该助手为DeepSeek，由深度求索公司创造。`）之后追加已保存的自定义提示词，两者之间以空行分隔。
- 自定义提示词为空或只含空白字符时，请求与现状完全一致，不追加任何内容。
- 修改提示词后，下一条消息即按新内容发送；已存在的会话同样生效，无需重建会话。历史记录只保存对话内容，不保存该提示词快照。
- 输入框拒绝超过 2000 字的内容（粘贴时按上限截断），并在保存与读取时再次校验，避免手动修改本地存储绕过限制。
- 补充中英文界面文案与相应样式，保持现有设置的视觉与无障碍交互模式。

## Capabilities

### New Capabilities

- `personalization`: 用户个性化设置。本次定义「提示词」入口、长度限制、本机持久化，以及自定义提示词与内置身份说明的组合和生效规则。

### Modified Capabilities

无。现有 `desktop-shell` 只约定设置随同一 origin 的本地存储恢复，本次不改变其要求。

## Impact

- **修改代码**：`src/services/settings.ts`（新增提示词状态与 localStorage 读写）、`src/components/settings/`（分组类型、导航项、个性化面板与输入样式）、`src/services/chat/store.ts`（请求的 `system` 字段按设置拼接）、`src/i18n/zh.ts`、`src/i18n/en.ts`。
- **新增图标**：设置导航使用一个个性化图标（在 `src/components/base/icons.tsx` 中新增）。
- **数据与兼容**：新增 `chat-demo:system-prompt` 本地设置键；不改 IndexedDB 结构、历史导入导出格式与 API 协议字段，旧版本数据可直接使用。
- **隐私**：提示词会随每次生成请求发送给模型服务；它不属于会话历史，不进入历史导出包。
- **范围外**：按会话单独覆盖提示词、多套提示词管理与快捷切换、提示词的导入导出、对已生成回复的回溯修改、对 Web 与桌面端的差异化处理。
