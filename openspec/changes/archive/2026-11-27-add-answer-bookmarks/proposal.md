# Proposal

## Why

现有收藏能力只能收藏整段对话，长对话中的某条关键回答仍需要手动翻找。用户需要把单条回答保存为书签，并从左侧书签列表直接回到原回答。书签是本机元数据，不属于 DeepSeek 兼容的历史归档格式，因此不随导出/导入迁移。

## What Changes

- 在每条已完成且有正文的助手回答操作区增加书签按钮：未保存为空心，已保存为实心品牌蓝；点击切换并提示「已添加书签」/「已移除书签」；流式回答和无正文回答不显示按钮。
- 侧栏标签页扩展为「全部 / 收藏夹 / 书签」三个；「书签」按保存时间倒序展示所有回答书签。
- 书签列表项显示回答摘要（最多两行）、来源对话标题和保存时间，不显示书签图标或其他前置图标。
- 点击书签项打开来源对话并定位到目标回答开头：若回答位于未选中的旧分支，先展开该分支；定位后不添加高亮、不添加选中背景，书签项也不保持选中态；移动端同时关闭抽屉。
- 书签保存在本机 IndexedDB 并跨重启保留；同一回答最多一条书签。书签不写入历史导出包，导入历史或清空全部历史时清空书签。
- 删除会话时在同一事务内级联删除该书签；删除失败回滚；其他会话的书签不受影响。删除确认弹窗文案保持不变。
- 「书签」没有内容时显示「暂无书签」和引导文案。
- 目标会话或回答已不存在时移除失效书签并提示；目标回答位于隐藏分支且来源会话正在生成时，不切换分支并提示。

## Capabilities

### New Capabilities

- `answer-bookmarks`: 回答级书签的入口、本机持久化、删除/历史替换清理，以及从书签定位到原回答的行为。

### Modified Capabilities

- `sidebar-navigation`: 标签页由「全部 / 收藏夹」扩展为「全部 / 收藏夹 / 书签」，新增书签列表项、空状态、实时更新与点击跳转入口。

## Impact

- 渲染层：`AssistantMessage` 操作区与书签图标、`Sider` 第三个标签页、新增书签列表项组件、空状态、轻提示。
- 数据层：IndexedDB 数据库版本 11 → 12，新增 `bookmarks` 对象仓库与 `sessionId` 索引；新增书签状态仓库、初始化/清理/失效清理逻辑。
- 会话导航：新增沿 `parentId` 展开隐藏分支的能力，以及跨会话定位到消息开头的一次性跳转状态；`MessageList` 消费定位请求。
- 国际化：中英文新增标签页、空状态、书签按钮、轻提示与失效提示文案；所有 key 保持一致。
- 非目标：不修改历史导出/导入格式；不修改删除确认弹窗文案；不改变移动端回答操作区现有显隐规则；不提供书签备注、重命名、拖拽排序或云端同步。
