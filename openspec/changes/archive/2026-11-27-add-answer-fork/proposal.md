# Proposal

## Why

现在想换一个方向继续追问，只能重新生成或编辑提问，新版本仍留在同一个会话里；一旦想从某条中间回答出发探索另一条路径，就会把两种尝试混在同一个会话的版本列表里。用户需要从任意一条回答「分叉」出去，在新对话里带着此前的完整上下文继续，而原对话保持不变。

## What Changes

- 每条有正文的已完成助手回答，在操作区新增「分叉」按钮（位于书签按钮之后、重新生成之前），悬停提示与无障碍名称为「分叉到新对话」。生成中的回答、被安全拒绝或没有正文的回答不显示该按钮。
- 点击后复制**当前可见分支路径**上「首条消息到该回答」的内容，创建一个独立的新会话：消息使用新的本地 ID，父子关系重建为单一路径；提问中的附件沿用同一份本机原件，不重复存储。
- 新会话沿用原会话标题，插入侧栏最前并立即切换过去；输入框为空，可以直接继续提问。原会话的消息、分支版本与时间均不变。
- 复制过去的回答保留原有模型、思考/搜索开关、系统信息快照与状态，后续提问因此和继续在原会话里对话一样进入请求上下文。
- 新会话不复制书签、收藏状态与草稿；不写入任何来源标记，也不改变历史导出/导入格式。
- 分叉期间沿用现有本机存储失败处理：新会话进入保存队列，失败时通过现有保存失败提示与重试入口恢复。
- 新会话的记忆处理进度从复制终点开始，避免把原会话已处理过的内容再次提取进长期画像。

## Capabilities

### New Capabilities

- `answer-forking`: 在回答操作区把某个回答及其之前的可见上下文分叉成独立新对话，并定义复制范围、新会话落位、后续继续对话与本机持久化的行为。

### Modified Capabilities

无。

## Impact

- 代码：`src/components/messages/AssistantMessage.tsx`（操作区入口）、`src/services/chat/fork.ts`（新增，按可见路径构造新会话）、`src/services/chat/store.ts`（新增分叉动作：创建、落盘、切换）、`src/services/chat/branches.ts`（复用可见路径计算）、`src/components/base/icons.tsx`（新增 16px 分叉图标）、`src/i18n/zh.ts` / `src/i18n/en.ts`（新增文案）。
- 存储：复用现有 `sessions` / `sessionSummaries` / `files` 存储，不升级 IndexedDB 版本，不改历史归档结构。
- 无 API、无后端、无依赖变更；不改动现有会话切换、分支版本、书签与记忆的既有行为。
