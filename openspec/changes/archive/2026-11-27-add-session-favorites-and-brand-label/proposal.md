# Proposal

## Why

侧边栏目前只有单一的时间分组列表，无法把重要对话单独归拢；同时左上角品牌名仍是「DeepSeek」，与应用名「DeepSeek Desktop」不一致。给会话增加本地收藏能力，并在列表上方提供「全部 / 收藏夹」切换，可以降低长会话列表的查找成本，也让应用内品牌名与产品名保持一致。

## What Changes

- 展开侧边栏左上角品牌文字由「DeepSeek」改为「DeepSeek Desktop」（中英文界面一致）。
- 在展开侧边栏「开启新对话」按钮下方新增「全部 / 收藏夹」两个标签页，默认选中「全部」；「全部」展示所有会话，「收藏夹」只展示已收藏会话，仍按现有时间分组与更新时间倒序排列。
- 会话条目的「更多」菜单新增「收藏 / 取消收藏」项，位于「重命名」与「删除」之间；点击后立即切换该会话的收藏状态，并弹出一次「已收藏」/「已取消」轻提示。
- 收藏状态保存在本机并跨重启保留；收藏/取消收藏不修改会话的更新时间，也不改变其在列表中的位置。
- 在「收藏夹」标签页下取消收藏时，该会话立即从列表中移除；正在查看的会话保持不变。
- 「收藏夹」没有会话时展示空状态提示。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `sidebar-navigation`: 新增品牌名称、会话收藏状态及「全部 / 收藏夹」标签页的行为要求。

## Impact

- 渲染层：`Sider`、`SessionItem`、`Menu` 选项与图标、轻提示文案。
- 数据层：`Session` / `SessionSummary` 增加收藏字段，IndexedDB 摘要与会话记录同步读写；不新增对象仓库，也不提升数据库版本。
- 国际化：中英文各新增品牌名、标签页、收藏菜单、轻提示与空状态文案。
- 非目标：不修改 Electron 窗口标题、应用菜单与关于信息中的品牌名；历史归档格式（导出/导入 ZIP）不携带收藏状态；不在会话行内额外展示收藏标记。
